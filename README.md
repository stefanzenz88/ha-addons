# SZE27 Home Assistant Add-ons

Eigene Add-ons für Home Assistant.

## Installation

Home Assistant → **Einstellungen → Add-ons → Add-on Store** → ⋮ → **Repositories** → URL hinzufügen:

```
https://github.com/stefanzenz88/ha-addons
```

## Add-ons

| Add-on | Beschreibung |
|---|---|
| [Checkmk](checkmk/) | Checkmk Community – Netzwerk- und Infrastruktur-Monitoring (SNMP, Ping, Agenten). Patch-Updates kommen automatisch. |
| [Netz-Köder](koeder/) | Honeypot fürs Heimnetz: meldet Verbindungsversuche auf Köder-Ports (FTP, Telnet, SMB, RDP …) an Home Assistant. |
| [Netz-Logsammler](logsammler/) | Syslog-Empfänger für die FortiGate: Archiv mit Suche, Upload je Gerät, Zielländer und auffällige Verbindungen als Meldung an Home Assistant. |
| [Netz-RADIUS](radius/) | FreeRADIUS für MAC-Authentifizierung der Switch-Ports; freigegebene Geräte aus dem Home-Assistant-Inventar, Ablehnungen als Push und im Audit-Log. |
